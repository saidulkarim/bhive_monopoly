# bHiVE Monopoly

**A bilingual strategic property-trading board game for Android and Web, built with Flutter.**

![Flutter](https://img.shields.io/badge/Flutter-02569B?logo=flutter&logoColor=white) ![Dart](https://img.shields.io/badge/Dart-0175C2?logo=dart&logoColor=white) ![Android](https://img.shields.io/badge/Android-3DDC84?logo=android&logoColor=white) ![Web](https://img.shields.io/badge/Platform-Web-blue)

bHiVE Monopoly combines classic property-trading gameplay with a modern responsive interface, intelligent computer opponents, smooth animations and a localized English and Bangla gaming experience.

## Major Development Activities

- Cross-platform game development for Android and Web.
- Game engine, financial rules and property management.
- Offline AI and local multiplayer gameplay.
- Responsive board design, animations and rendering optimization.
- Bilingual localization and structured game activity tracking.
- Game persistence, automated testing and regression testing.

## Game Features

- 40-space board with properties, railway stations, utilities and special spaces.
- Property purchasing, rent collection, auctions and trading.
- House and hotel construction, mortgages and debt management.
- Local pass-and-play, LAN multiplayer and offline computer opponents.
- Four AI difficulty levels: Easy, Normal, Hard and Expert.
- Saved-game restoration, match history and customizable preferences.

## Unique Features

- **Bilingual board:** International property names in English and recognizable Bangladeshi locations in Bangla.
- **Strategic offline AI:** Risk-aware investment, competitive bidding, trade evaluation and cash management without external AI services.
- **Immersive board:** 2D and 3D views, animated dice, smooth token movement, manual zoom and camera controls.
- **Dynamic game activity:** Localized events, category icons, player filters and financial indicators.
- **Localized experience:** English and Bangla typography, numerals and configurable currency display.
- **Responsive design:** Consistent dark-and-gold interface across phones, tablets and web browsers.
